# ComfyDiff 工作流 Git 差异需求

在 ComfyUI 左侧的「工作流差异」中，可以将当前标签页对应的磁盘文件或画布快照与 Git `HEAD` 比较。切换标签页时，侧栏自动跟随。选中差异可查看详情和画布标记；点击节点 ID 或行内定位图标可移动到对应位置。「问题」标签可查看 ComfyUI 报告的工作流问题。

## 运行环境

插件需要在 ComfyUI 设置中启用 **Nodes 2.0**，前端 `1.57.6` 是开发和验收基线。经典模式下，侧栏显示「请在 ComfyUI 设置中启用 Nodes 2.0」。侧栏通过 ComfyUI 扩展接口注册。 [ComfyUI 侧栏文档](https://docs.comfy.org/custom-nodes/js/javascript_sidebar_tabs)

## 工作区与当前标签页

- 在侧栏右上角菜单打开「Git 工作区设置」，填写服务器上的 Git 工作区根目录的绝对路径。后端验证该目录，并将工作流文件读取限制在工作区内的普通 JSON 文件。
- 侧栏显示当前标签页和用于比较的仓库相对路径。对已保存的标签页，优先用其实际指向的仓库文件，其次用已记住的手动关联。前两项都无法确定时，用 ComfyUI 路径中 `workflows/` 之后的完整相对路径匹配，例如 `portraits/sdxl.json`。当导入只保留 `sdxl.json` 时，自动匹配只检查工作区根目录下的 `sdxl.json`。
- 未识别路径时可用「关联仓库文件」，已有手动关联时可用「更改当前标签页关联」。手动关联只选择比较对象。已保存工作流的关联按 ComfyUI 用户、完整工作流路径和 Git 工作区记住。临时工作流的关联记在当前标签页实例上。切换工作区时重新解析。磁盘比较中，若手动关联的文件已移动或删除，侧栏保留关联路径、显示读取错误，并允许重新选择。
- 从右上角菜单使用「在新标签页打开仓库文件」时，ComfyUI 按导入工作流处理，创建临时标签页。插件为该标签页记住仓库相对路径，并自动比较。原生保存由 ComfyUI 处理，保存时需确认目标路径。「磁盘文件」始终读取侧栏显示的仓库路径。

## 比较来源与刷新

- 两种模式都用当前 Git 检出位置的 `HEAD` 提交作为基线。每轮先解析提交号，再读取其中对应路径的工作流。侧栏显示短提交号和完整仓库相对路径。 [Git 提交与路径寻址](https://git-scm.com/docs/gitrevisions)
- 默认「磁盘文件」对应 `HEAD ↔ 工作区`。右侧读 Git 工作区里该路径的磁盘 JSON，适合审查 AI 已保存的修改。即使先暂存再修改，仍以磁盘最终内容为准。
- 「当前画布」对应 `HEAD ↔ 当前画布`。进入该模式时采集整个根工作流的快照，包含尚未保存的编辑，即使用户当前位于子图。继续编辑后点击「刷新比较」重新采集。 [ComfyUI 根图和子图](https://docs.comfy.org/custom-nodes/js/subgraphs)
- 打开侧栏、切换标签页或选定对应文件时立即读取。侧栏可见且选中「磁盘文件」时，定期检查对应仓库文件和 `HEAD` 是否变化，包括 AI 直接写盘的情况。切换标签页、对应文件或比较来源后，丢弃上一轮迟到的结果。
- `HEAD` 中没有该路径、而新版有效时，显示「新文件」并列出新增项。仓库没有提交、文件缺失、读取失败或 JSON 无效时，说明发生在哪一侧。无差异与读取失败使用不同提示。

例如，提交里的 `steps` 是 `20`，AI 把磁盘文件改为 `28`，随后用户在画布改成 `32` 且尚未保存。磁盘比较显示 `20 → 28`，画布比较显示 `20 → 32`。

## 差异内容

工作流以编辑器序列化 JSON 为输入，覆盖 Workflow JSON 0.4、子图中的对象连线及前端写出的具名参数。比较识别节点增删、类型替换、控件参数、运行模式、接线和子图接口，忽略纯格式、布局、缩放、节点排列和连线 ID 重编号。 [Workflow JSON 0.4](https://docs.comfy.org/specs/workflow_json_0.4)

| 差异 | 侧栏内容与目标 |
| --- | --- |
| 新增节点 | 列表显示节点名称、ID 和端口数量。行内图标定位新版节点。 |
| 删除节点 | 选中后在底部详情查看旧参数、模式、上游来源和下游去向，同时在对应图层预览旧节点和原接线。 |
| 类型替换 | 同一图层内，同一 ID 的节点类型变化时列为一条替换，例如 `#37 PreviewImage → SaveImage`。行内图标校验并定位新版节点。 |
| 参数与模式 | 显示旧值 → 新值，例如 `KSampler.steps 20 → 28`。优先取序列化参数名。位置数组仅在能确认槽位对应关系时标名，其余显示「参数 3」这类序号。 |
| 参数与接线转换 | 对同一输入显示一条来源变化，例如 `KSampler.steps 20 → #31 Primitive.INT` 或反方向的 `#31 Primitive.INT → 28`。 |
| 新增、移除或改接线 | 每个变更按接收输入端口展示。详情列出两侧的来源节点 ID、名称和输出端口，空来源显示「未连接」。例如 `KSampler.model` 的 `#12 CheckpointLoader.MODEL → #31 LoraLoader.MODEL`。行内图标定位仍存在的接收节点。 |

节点身份按所属图和节点 ID 判断。本机前端的原地替换会沿用节点 ID，符合上述规则。如果操作删除旧 ID 并创建新 ID，两份快照按实际结果显示一条删除和一条新增。相近的位置或相似接线不足以确认替换关系。 [原地替换实现讨论](https://github.com/Comfy-Org/ComfyUI_frontend/issues/12882)

第三方节点优先展示工作流保存的注册包标识或扩展来源，其次使用 ComfyUI 已注册的节点定义提供的模块名。纯前端类型显示「前端节点」。未注册类型可用 ComfyUI Manager 的本地索引查询候选扩展包，有歧义时保留候选列表。参数优先使用工作流里的具名值。旧版只有位置数组时，节点类型须已注册且已知的包和版本标识须一致。端口和参数数量一致，或保存值能按顺序唯一对应当前控件时，借用当前控件名。无法确认时显示序号。

## 侧栏筛选与子图

- 比较整个工作流时递归检查嵌套子图，结果按图层路径归组，例如「主图 › 精修 #45 › 采样 #7」。可搜索节点名、参数名或 `#ID`，并在「差异范围」中选择「主图和子图」「仅主图」或有差异的具体子图。通过「全部」「参数」「接线」「节点」「端口」切换类别，数字按搜索和范围统计差异条数。「接线」包含输入来源变化，「参数」包含运行模式，「端口」对应子图接口。
- 同一图层中同一节点有多处匹配差异时，合并为一个可展开的节点条目，搜索时展开匹配结果。只匹配一处时直接显示该差异。列表可独立滚动。选中差异时底部显示详情，可拖动分隔条调整高度。悬浮或聚焦差异行时显示定位图标。收起所选差异所属节点、再次点击当前项或筛选掉该项时，收起详情并清理高亮。
- 列表、接线来源、详情、子图路径及只读预览中的节点 ID，悬浮或用键盘聚焦时显示下划线，点击后定位到该 ID 对应的节点。行内定位图标定位整处差异，例如把参数控件或旧接线纳入视口。
- 子图内部变化按定义比较。多个实例共用同一个定义时，内部差异列一次。点击时优先进入当前路径上的有效实例，其他情况下使用侧栏显示的实例路径。每一级定位都校验实例身份与子图定义。 [ComfyUI 子图节点身份](https://docs.comfy.org/custom-nodes/js/subgraphs)
- 父图上的外部接线或暴露参数的实例值变化，定位到父图里实际变化的那个子图实例和对应端口或控件。子图定义的输入输出增删、重命名及内部接线变化，定位到子图内对应的边界端口或节点。参数从内部暴露到父图或取消暴露时，按可确认的映射显示其边界来源变化，例如「本地值 `20` → 子图输入 `steps`」。 [ComfyUI 子图与参数暴露](https://docs.comfy.org/custom-nodes/js/subgraphs#widget-promotion)

## 参数值与接线来源

对于可接线的参数，先确认控件与输入端口对应的是同一字段，再比较两侧当前生效的来源。接线有效时，来源显示为上游节点与输出端口。断开后恢复可编辑参数时，来源显示为保存的本地值。端口仍未连接且没有本地参数时，显示「未连接」。识别优先用保存的控件与端口映射，或可唯一确认的节点定义。槽位序号可能随序列化变化。 [ComfyUI 参数序列化](https://github.com/Comfy-Org/ComfyUI_frontend/blob/main/docs/WIDGET_SERIALIZATION.md)

同一字段在「本地值」和「连接」之间切换时合成一条差异。接线生效时忽略文件里残留的控件值。只有暴露的端口且尚无接线时，显示「已暴露，未连接」。仍有可编辑控件的值按本地参数比较。控件与端口的关系无法可靠确认时，分别报告已确认的变化。`StringFunction|pysssss` 的只读运行结果也从参数比较中排除。

## 画布定位与 Git 配色

选中差异时立即在对应图层绘制节点、控件、端口或接线标记，视口和画布上的节点选择保持原样。如果目标在另一图层，进入该图层后自动显示标记。取消选中时清除标记。

点击「定位到画布」时，先检查当前标签页、完整子图路径、目标节点 ID、类型和本条差异涉及的值或端口连接。检查通过后进入目标层级，移动视口并选中节点。跳转最多放大到 90%，需要展示更多接线或节点时继续缩小。若检查发现画布与比较结果不符，侧栏说明具体原因，保留原视口、选中节点和未保存编辑。磁盘比较定位失败时，可用「比较当前画布并定位」重新比较。同一项仍有差异时定位到新结果，找不到时显示提示。画布无未保存编辑时，也可用「在当前标签页载入磁盘版本」。

差异标记沿用 Git 的 **绿色 `+` / 红色 `−`** 语义。画布用黄色边框标识已修改的控件或节点，侧栏继续用红绿显示旧值和新值。亮色和暗色主题下都保留文字和符号，原生选中样式表示交互焦点。 [Git Diff 配色](https://git-scm.com/docs/git-config)

| 差异 | 图上标记 | 侧栏 |
| --- | --- | --- |
| 新增节点 | 绿色实线框和 `+`。 | 列表显示绿色 `+`，详情显示「新增节点」。 |
| 参数值修改 | 用黄色边框圈出对应控件。 | 红色 `−` 旧值，绿色 `+` 新值。 |
| 运行模式或类型变更 | 黄色节点边框。 | 详情显示「运行模式」或「替换」，并列出前后值。 |
| 参数变成接线 | 黄色圈标出目标输入端口，新线加绿色描边。 | 例如红色 `− 20` → 绿色 `+ #31 Primitive.INT`。 |
| 接线变回参数 | 黄色边框圈出回到节点上的控件，旧线显示为半透明红色虚线。 | 例如红色 `− #31 Primitive.INT` → 绿色 `+ 28`。 |
| 新增或改接线 | 沿实际连线加绿色外描边，保留线芯的端口类型颜色，并用黄色圈标出目标输入端口。改接线同时显示半透明红色虚线旧连接。 | 详情显示新旧来源。 |
| 删除节点 | 在当前画布的旧坐标显示半透明节点，带红色虚线框和 `−`。 | 列表显示红色 `−`，选中后显示旧节点详情。 |
| 移除连线 | 显示半透明红色虚线，连到可确认的现有端口或旧端口位置。 | 详情显示旧来源及当前的「未连接」。 |
| 子图接口端口变更 | 用黄色圈标出新增或变更后的端口，用红色虚线圈标出已移除端口的旧位置。 | 详情显示前后端口名称和类型。 |

目标控件或端口被折叠、隐藏或无法可靠匹配时，用黄色边框标出所属节点，侧栏保留已确认的字段信息。参数只能定位到节点时，侧栏说明原因。高节点上的可见参数优先进入视口中心区域。画布标记只存在于当前审查视图。关闭侧栏、切换工作流或切换来源时，清理原视图的标记。明显性以能在原生选中、高密度接线、缩放和子图切换时分辨目标为准。 [Wedge Diff 交互参考](https://comfy.icu/extension/Gerry-Malta__ComfyUI-WedgeDiff)

## 删除预览

两种比较模式都支持删除预览。选中删除项时，侧栏显示旧详情，画布使用本轮 `HEAD` 快照在对应图层绘制半透明标记。标记跟随画布缩放和平移。点击删除行的节点 ID 或「在画布查看删除」图标可移动到目标。

- 删除节点时，在原坐标显示节点名称、ID 和端口，以半透明背景和红色虚线框区分，并画出已移除的入线和出线。旧节点显示在现存节点上方，可以拖动、折叠和复制参数。
- 移除或改接线时，从旧快照读取两端和已有的转接点。仍能匹配的端口使用当前画布上的位置。接线变回参数时，旧线指向当前控件。旧端点所属节点已删除时，同时显示该旧节点，并把虚线接到其端口。改接线同时显示红色虚线旧线和绿色描边新线。
- 节点原本所在的子图仍存在时，进入该层显示标记。若整层已删，在最近仍存在的父图显示半透明的原入口。点击入口上的「查看已删除子图」，在当前标签页内打开本轮 `HEAD` 快照中的只读子图。也可以从侧栏打开同一视图。若从内部差异进入，直接定位到旧路径上的目标。
- 如果磁盘比较中的删除对象仍存在于当前画布，提示画布与磁盘版本不同，并沿用现有的版本处理流程。选择另一项差异、切换工作流或来源、关闭侧栏时，清除当前的删除标记。

删除预览属于画布上的临时叠层。旧节点可点选和查看参数，参数保持只读。「查看已删除子图」在旧入口上打开只读子图。只读子图可平移、缩放和继续进入旧的嵌套子图。关闭后回到打开前的父图，保留视口、选中项和未保存编辑。保存、执行和撤销均使用真实工作流。

## 工作流问题

「问题」标签跟随当前工作流，即使未设置 Git 工作区或未关联仓库文件也可查看。列表按「缺少模型」「缺少节点」「缺少素材」「参数校验失败」「运行失败」分组，各分类可折叠。可以按节点名、`#ID`、文件名或报错内容搜索。

- 缺失模型按模型目录和文件路径合并，缺失节点按节点类型合并。一个条目下按完整节点 ID 去重。不同子图实例中的同一内部节点分别计数。ComfyUI 未提供节点 ID 时，界面标出已知的节点数或提示数量未知。
- 展开条目可查看受影响的节点。点击可解析的节点 ID 或行内定位图标可进入对应的图层并选中节点。「问题」标签上的数字统计合并后的全部问题条目，分类标题上的数字随搜索结果更新。

## 实现边界

仓库读取模块负责提供提交和磁盘快照。工作流比较模块从两份快照生成结构化差异，包含旧值、新值与图和端口身份。侧栏与画布模块负责快照采集、状态提示、定位与临时标记。Git 和比较逻辑无需依赖任何画布渲染器。

Nodes 2.0 的节点和控件标记使用 Vue 节点对应的 DOM 元素。当前连线的描边复用前端已绘制的路径。删除预览从旧快照读取节点边界、端口和连接，随当前视口绘制。标记仅用于审查视图，工作流序列化和撤销记录以实际编辑为准。 [连线绘制与路径源码](https://github.com/Comfy-Org/ComfyUI_frontend/blob/main/src/renderer/core/canvas/litegraph/litegraphLinkAdapter.ts)

## 当前版本验收场景

用已有 `HEAD` 提交的 Git 工作区验收。比较样本可包含普通节点、接线、嵌套子图，以及共用同一子图定义的多个实例。

1. **仓库路径与手动关联。** 在「Git 工作区设置」填入工作区根目录。准备 `portraits/sdxl.json` 和 `tests/sdxl.json`，并让二者有不同改动。切换带完整路径的标签页，确认自动比较各自文件。在仓库根目录没有 `sdxl.json` 时，导入只带该文件名的工作流，确认侧栏要求手动关联。保存一个需要手动关联的工作流，设置关联后关闭并重新打开，确认可以恢复关联。切换工作区时确认会重新解析路径。移走手动关联的磁盘文件，检查原路径、读取错误和重新选择入口。
2. **从仓库打开与原生保存。** 用「在新标签页打开仓库文件」打开一个嵌套路径下的 JSON，确认创建新标签页、画布载入文件且侧栏立即比较完整仓库路径。修改画布，用 ComfyUI 原生保存将副本存到工作区外，核对实际保存位置和仓库原文件的内容。确认侧栏比较路径，必要时重新关联。用「磁盘文件」核对仓库文件的值，用「当前画布」核对保存到副本的值。
3. **磁盘刷新与错误。** 在侧栏打开期间直接修改已关联的仓库 JSON，确认「磁盘文件」自动更新。暂存后再次修改，确认结果反映最终磁盘值。提交后检查 `HEAD` 短号和差异一同更新。比较 `HEAD` 中还没有的有效工作流时检查「新文件」提示，再用无效 JSON 验证提示会标明出错的一侧。
4. **画布快照。** 进入一个子图，并在画布保留未保存改动。选中「当前画布」，确认比较覆盖主图和子图。继续改值后点击「刷新比较」，确认结果反映新值。切回「磁盘文件」时核对磁盘值。
5. **差异分类和节点身份。** 只改 JSON 格式或节点布局时检查零差异。分别修改节点、参数、运行模式、接线和子图接口，检查差异类别。同一图层中同 ID 换类型时，详情显示「替换」和前后类型，行内定位在新版节点上画黄色边框。换成新 ID 时，检查一条删除和一条新增。
6. **筛选、归组和详情。** 给同一节点制造多处差异，验证合并条目可展开、计数按差异条数统计。搜索时检查匹配的条目展开，只有一个匹配项时直接显示该项。切换「仅主图」、具体子图和类别，核对列表及数量。点击行检查底部详情和即刻绘制的画布标记，确认视口保持原位。悬浮或聚焦节点 ID 检查下划线，分别点新旧接线来源的 ID 检查跳转。拖动分隔条，检查列表独立滚动。收起节点、取消选中或筛选掉当前项时，检查详情和画布高亮清理。
7. **子图定位。** 修改共享子图定义内的参数，确认内部差异只列一次，行内定位优先使用当前路径上的有效实例。修改一个实例暴露在父图的参数，确认定位到该实例。再定位嵌套子图内的变化，检查图层路径和黄色控件边框。折叠目标节点或使用无法唯一匹配的旧版参数，检查节点级高亮及提示。
8. **接线和来源。** 将参数从本地值切换为接线，再断开恢复本地值，分别检查每个方向只显示一条来源变化。验证已暴露但未连接的显示，并检查仅改动已接线参数的残留值或 `StringFunction|pysssss` 的只读结果时显示零差异。用包含密集接线和转接点的样本检查新线绿色描边、线芯原有的端口类型颜色、红色虚线旧线和黄色目标标记。
9. **删除预览。** 分别从根图和嵌套子图内的删除行点击「在画布查看删除」，检查旧节点、参数和旧线。拖动旧节点或平移缩放画布，检查虚线跟踪端口。检查单独移除连线和改接线的预览。删除整层子图后，从半透明入口和侧栏分别打开只读视图，进入旧的嵌套子图，再返回原父图。核对打开只读视图前后的视口、选择和编辑状态。
10. **定位失败与恢复。** 在仓库文件中修改参数、删除节点或替换类型，让当前画布仍保留旧状态。用「磁盘文件」定位，检查具体的失败提示。画布有未保存编辑时，检查视口、选择和编辑是否保留，并用「比较当前画布并定位」重新查找该差异。画布无未保存编辑时，验证「在当前标签页载入磁盘版本」。
11. **主题与模式。** 在亮色和暗色主题下定位新增、删除和修改项，检查颜色和符号。关闭侧栏、切换标签页或比较来源时，检查原标记清理。关闭 Nodes 2.0 后检查启用提示。
12. **问题分组与定位。** 打开未关联仓库的工作流，用多个节点和子图实例引用同一个缺失模型，并由另一个模型目录引用同名文件。确认同一目录及路径合并为一条，按完整节点 ID 计数，不同目录各自显示。检查相同缺失节点类型合并、缺失素材分类、折叠分类和按节点名、`#ID` 或文件名搜索。点击可定位项检查对应节点，核对搜索时分类计数和「问题」标签的总数。
13. **校验与运行问题。** 分别触发参数校验失败和运行失败，检查类别、报错内容搜索和可定位节点。切换到另一工作流，检查问题列表及数量随活动标签页更新。

## 后续历史版本 A/B

计划在侧栏增加「比较历史版本」。以当前标签页对应的仓库相对路径为准，从文件提交记录分别选择 A 和 B。每条记录显示提交短号、日期和摘要，也可以输入本地仓库中的提交号。A 是比较基线，B 是比较目标，允许选择任意两个可读提交，交换顺序会反转新增和删除。插件直接从各自提交读取同一路径的 JSON。 [Git 文件历史](https://git-scm.com/docs/git-log) · [Git 提交与路径寻址](https://git-scm.com/docs/gitrevisions)

结果在同一浏览器标签页内显示两份并排的只读图和一份差异列表。两侧各自显示提交号与子图路径，允许独立平移和缩放。

- 删除项在 A 侧定位，显示红色虚线节点框或旧连线。新增项在 B 侧定位，显示绿色实线节点框或连线描边。
- 参数、运行模式和类型变化在两侧定位各自节点。参数用黄色边框标出对应控件，侧栏显示 `−` 旧值和 `+` 新值。
- 改接线时，两侧都聚焦接收输入。A 标红旧来源的整条线，B 标绿新来源的整条线。参数与接线互换时，各侧定位实际存在的控件或端口。目标位于子图中时，两侧沿各自快照进入对应图层。

文件仅存在于一侧时，将另一侧标为「该提交无此文件」，结果显示整份工作流的新增或删除。两侧均无文件时提示没有可比较的工作流。提交无法读取或 JSON 无效时，标明具体一侧及原因。

验收时选择两个都早于当前 `HEAD` 的提交，验证新增、删除、改接线的高亮落在正确一侧。交换 A、B，确认新增和删除互换。关闭历史比较后，回到原工作流及原未保存编辑。
